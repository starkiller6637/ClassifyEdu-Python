# Código histórico

Esta carpeta conserva módulos de una etapa anterior de **ClassifyEDU — Python (v1)**. Se trasladaron aquí **sin modificar su contenido**, para distinguirlos de los módulos utilizados al ejecutar `python main.py`.

- `gui.py`: interfaz alternativa incompleta; contiene referencias a imports y recursos de la versión antigua.
- `lectura_archivos.py`: clasificación preliminar de documentos mediante coincidencias de texto.
- `organizador.py`: organizador previo basado en nombre y extensión.

**No son parte del flujo activo** y no se garantiza que puedan ejecutarse directamente. Se incluyen como referencia de la evolución del prototipo.
